# BIST Hisse Avcısı V7

Bu sürüm:
- Yaklaşık 500 BIST hissesini tarar.
- En çok yükselen 10 / düşen 10 listesini gösterir.
- 3 Güçlü Al + 3 Al + 3 Sıkışma/Kırılım adayı seçer.
- Hisseye tıklayınca mum grafik, RSI, hacim, sıkışma, kırılım, destek/direnç, alım bölgesi, hedef ve stop gösterir.
- TradingView'de aç butonu verir.

## Kurulum

```bash
python -m pip install -r requirements.txt
python app.py
```

Sonra telefondan/PC'den:
http://127.0.0.1:5000

Telefon aynı Wi-Fi'daysa bilgisayarın yerel IP'siyle:
http://BILGISAYAR_IP:5000
